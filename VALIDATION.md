# Фактическая проверка

Дата: 27 ноября 2026, Windows, Flutter 3.47.4 / Dart 3.13.3.

- `flutter gen-l10n`: успешно, русский ARB преобразован в Dart.
- `dart format lib test`: выполнен.
- `flutter analyze --no-pub`: No issues found.
- `flutter test --no-pub`: 7 тестов прошли. Шесть тестов контроллера и один widget-тест поворота/полноэкранной картинки/системного Back.
- Локальный mock: реальные HTTP-проверки входа, списка каналов, страницы из 20 сообщений, отправки и PNG прошли.
- Официальный сервер: без авторизации прочитаны /channels (133 строки) и /channel/1@channel (20 сообщений). Формат совпал с моделями id/from/to/data/time. Публичные сообщения не включены в комплект.
- Вход/отправка в официальный сервер не проверялись: учётные данные пользователя не предоставлены, аккаунт от его имени не создавался.
- Android debug APK собран. Исходная сборка с mock-адресом завершилась успешно; окончательная сборка использует официальный API по умолчанию.
- Устройств в `adb devices` нет: ручные сценарии на телефоне/эмуляторе, фактическое Android KeyStore, перезапуск процесса с дисковыми черновиками, жест масштабирования и системная доступность на устройстве требуют демонстрации по README.
- iOS: платформенный проект включён, сборка и тестирование не выполнялись (нужны macOS и Xcode).

В процессе установки Dart pub зависал при обращении к каталогу. Зависимости скачаны через временный локальный ретранслятор официального pub.dev; содержимое пакетов не менялось. В итоговом pubspec.lock адрес источника нормализован к https://pub.dev. Ретранслятор не требуется для запуска или сборки проекта в обычной сети.

Предупреждения инфраструктуры сборки: Java 25 сообщает о будущем ограничении native-access в библиотеке Gradle; Java-компиляция плагина secure_storage 9.x сообщает об устаревающих source/target 8. Это предупреждения сторонних инструментов/плагина, а не ошибки Dart; анализатор приложения чистый. Они не блокируют текущую Android debug сборку.

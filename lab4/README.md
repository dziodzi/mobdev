# Лабораторная 4: Android-чат с кэшированием


Аккаунт создаётся на https://faerytea.name/adduser.html; ссылка доступна на экране входа.

## Проверка

- Вход: пустые поля, неверный пароль, успешный вход и повторный запуск.
- Каналы: обновление, открытие, отметка выбранного канала в альбомном режиме.
- Сообщения: новая отправка появляется снизу; пустой текст не отправляется.
- При отключённой сети отправка сохраняет текст в постоянной очереди. После восстановления сети очередь отправляется автоматически.
- Черновики сохраняются отдельно в каждом канале при переключении и повороте.
- Обновление загружает новые сообщения, история подгружается назад, каждый запрос ограничен 20 сообщениями.
- Загрузка истории сохраняет место чтения; отправка своего сообщения прокручивает список вниз.
- Изображение открывается полностью; доступны закрытие, системный «Назад» и повтор загрузки при ошибке.
- Поворот сохраняет открытый чат, включая поворот при открытом изображении. Загрузка сообщений находится во ViewModel, а не во фрагментах.
- В альбомном режиме каналы слева, сообщения справа. «Назад» закрывает выбранный чат.
- Выход немедленно открывает экран входа. Поздние ответы запросов старой сессии не восстанавливают её.
- Светлая и тёмная темы, длинные сообщения, увеличенный системный шрифт и клавиатура.

Регрессионные тесты: `lab4_app/src/test/java/ru/ivan/mobchat/ChatRegressionTest.kt`.
Запуск через контекстное меню тестового класса в Android Studio.
Gradle-задачи: `:lab4_app:assembleDebug :lab4_app:testDebugUnitTest :lab4_app:lintDebug`.

Входящие сообщения обновляются вручную: кнопкой обновления или жестом обновления списка.
Учётные данные сохраняются локально в SharedPreferences согласно допущению задания; резервное копирование приложения отключено.

# Каналы

Лабораторная работа № 3 по мобильной разработке. Приложение на Dart и Flutter для Android. Пакет называется ru.itmo.mobile.channel_chat.

## Запуск

Понадобятся Flutter 3.47, Dart 3.13 и Android SDK.

1. Откройте папку проекта в VS Code.
2. В Android Studio откройте Device Manager и запустите Android-эмулятор.
3. В терминале VS Code из папки проекта выполните команды:

~~~powershell
flutter pub get
flutter run
~~~

Если подключено несколько устройств, выберите эмулятор в терминале. Приложение подключается к учебному серверу по HTTPS. Для входа используйте свой логин и пароль. [Регистрация](https://faerytea.name/adduser.html) · [Документация API](https://faerytea.name/static/howto.md)

## Как устроено приложение

- `lib/data/chat_api.dart` читает каналы и историю, выполняет вход и отправку через `http`. Таймаут, отказ сервера и ошибка авторизации обрабатываются отдельно.
- `lib/state/chat_state.dart` хранит сессию, выбранный канал, историю и черновики через `ChangeNotifier`. После защищённого ответа 401 приложение возвращается на экран входа. Результат запроса привязан к исходному каналу и сеансу.
- История загружается по 20 сообщений с курсором по ID. Новые и старые сообщения добавляются по разные стороны от исходной страницы. Подгрузка истории сохраняет позицию просмотра. Повторный ответ с тем же ID обновляет существующее сообщение.
- Токен хранится через `flutter_secure_storage` с Android Keystore. Черновики и незавершённые отправки сохраняются в `SharedPreferencesAsync` отдельно для каждого логина. Кнопка выхода удаляет данные текущего пользователя. После истечения токена черновики восстанавливаются при повторном входе с тем же логином.
- До отправки запись сохраняется локально. При потере ответа пользователь видит неопределённый статус. Ручной повтор обновляет ту же запись и требует подтверждения. После успешного ответа запись связывается с ID сервера. Если пользователь успел изменить черновик, новый текст сохраняется.

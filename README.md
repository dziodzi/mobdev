# Лабораторная работа №3. Чат с базой данных

Клиент Flutter для Android. Он показывает каналы, загружает историю страницами по 20 сообщений, отправляет текст и открывает изображения. Для подключения используется [API сервера курса](https://faerytea.name/static/howto.md).

## Запуск

Откройте каталог проекта в Android Studio, запустите Android-эмулятор и выполните:

```powershell
flutter pub get
flutter run
```

Введите имя и пароль своего аккаунта. Если аккаунта ещё нет, его можно создать на [странице регистрации курса](https://faerytea.name/adduser.html). Пароль вводится в приложении.

## Как работает код

- `lib/main.dart` восстанавливает сеанс, показывает форму входа или список каналов. При выборе канала открывает экран чата.
- `lib/chat_api.dart` отправляет HTTP-запросы, разбирает сообщения из JSON и передаёт токен для отправки и выхода.
- `lib/chat_screen.dart` показывает историю, объединяет страницы по идентификатору сообщения и сохраняет ввод. Кнопка обновления запрашивает последние сообщения.
- `lib/chat_storage.dart` хранит токен в защищённом хранилище, а черновики в SQLite. Ключ записи состоит из имени пользователя и канала.

## Демонстрация

Подробные инструкции и вопросы для защиты доступны [на русском](DEFENSE_GUIDE_RU.md) и [на персидском](DEFENSE_GUIDE_FA.md).

1. Войти и выбрать канал. Показать историю и загрузить более старые сообщения.
2. Открыть миниатюру и увеличить изображение жестом.
3. Написать черновик, вернуться к списку каналов и снова открыть чат. Текст должен восстановиться.
4. Отправить текст в канал, где разрешено тестирование, и показать результат. При спорной ошибке отправки сначала обновить историю, затем решить, нужен ли повтор.
5. Повернуть эмулятор и проверить содержимое экрана. Выйти из аккаунта через меню каналов.

В предоставленном примере черновики записываются через SharedPreferences. Здесь для них используется таблица SQLite. Русские подписи находятся в коде интерфейса. Клиент использует ручное обновление и показывает изображение из истории.

# Работа с лабораторными в репозитории mobdev

## Лабораторная №1 на Swift — ветка `lab-1-swift`

В папке [`lab1-swift`](lab1-swift) находится iOS-приложение «Продвинутый калькулятор» на Swift и SwiftUI. Существующий Android-проект сохранён без изменений.

Для запуска на Mac откройте `lab1-swift/AdvancedCalculator.xcodeproj` в Xcode 15 или новее, выберите симулятор iPhone с iOS 16 или новее и нажмите **⌘R**. Swift отдельно устанавливать не нужно. Тесты в Xcode запускаются через **⌘U**; независимые тесты вычислительного ядра — командой `swift test` из папки `lab1-swift`.

Подробности: [инструкция и описание реализации](lab1-swift/README_RU.md), [результаты проверки](lab1-swift/TEST_RESULTS.md). Проверены 49 автоматических тестов логики. Сборка и визуальная проверка iOS-интерфейса в среде подготовки не выполнялись, поскольку в ней нет Xcode и iOS SDK.

В репозитории должны находиться **6 лабораторных работ**. Каждая лабораторная - это **отдельное приложение в отдельной ветке**.

Каждая ветка lab-X содержит:

src/main/java   — код лабораторной работы  
src/test/java   — тесты для проверки задания (если требуются)
### 1. Клонирование репозитория

git clone https://github.com/dziodzi/mobdev
cd java-application-development

### 2. Работа с лабораторной

Каждая лабораторная выполняется в своей ветке.

### 3. Создание рабочей ветки

Работу необходимо выполнять в отдельной ветке, созданной от master.

- Убедитесь, что вы находитесь на ветке master:

`git checkout master`
- Получите последние изменения:

`git pull`
- Создайте свою рабочую ветку:

`git checkout -b lab-1`

После этого все изменения выполняйте только в этой ветке.

- Проверить текущую ветку можно командой:

`git branch`

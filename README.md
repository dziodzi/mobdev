# Лабораторная работа №2 - Контакты

Приложение на Flutter для просмотра и поиска контактов устройства.

## Возможности

- запрос разрешения на чтение контактов;
- отдельные состояния загрузки, отказа, ошибки и пустой адресной книги;
- список с именем, основным номером телефона и признаком наличия email;
- экран подробной информации о контакте;
- поиск по имени без повторного чтения адресной книги;
- сортировка по имени в прямом и обратном порядке;
- отображение количества найденных контактов;
- повторная проверка разрешения после возвращения из настроек;
- сохранение поиска и сортировки при повороте экрана;
- локализованные строки интерфейса на русском и английском языках.

## Структура

- `lib/models/contact_record.dart` - модель контакта;
- `lib/services/contact_repository.dart` - разрешение и чтение контактов;
- `lib/controllers/contact_controller.dart` - состояние, кеш, поиск и сортировка;
- `lib/ui/contacts_page.dart` - список и экран деталей;
- `lib/l10n/` - ресурсы локализации;
- `test/` - тесты контроллера.

## Проверка

```sh
flutter analyze
flutter test
flutter run
```

Для полной проверки требуется Android-эмулятор или реальное устройство с
несколькими контактами.

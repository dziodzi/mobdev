# Лабораторная работа №3. Запуск и защита

## Как запустить приложение

1. Откройте папку проекта в Android Studio. Запустите Android-эмулятор в Device Manager и выберите его в списке устройств.
2. Выполните `flutter pub get` и `flutter run` в терминале проекта. Можно также запустить `lib/main.dart` кнопкой Run.
3. Если аккаунта ещё нет, откройте [форму регистрации чата](https://faerytea.name/adduser.html). Введите имя и сохраните пароль, который даст сервер. После отправки формы адрес может измениться на `/addusr`.
4. Введите имя и пароль чата на экране «Вход». После успешного входа откроется список каналов.

## Как работает код

1. **`lib/main.dart`**. Функция `main()` запускает `ChatHome`. Метод `_restore()` ищет сохранённый сеанс. Без сеанса видна форма входа. Метод `_login()` получает и сохраняет токен. Метод `_start()` начинает загрузку каналов. `FutureBuilder` показывает загрузку, ошибку, пустой список или каналы. Нажатие на канал открывает `ChatScreen`. При обычном выходе `_logout()` удаляет сеанс и черновики пользователя.
2. **`lib/chat_api.dart`**. В `Session` есть имя и токен. В `Message` есть ID, автор, текст или путь к картинке. `_body()` проверяет HTTP-ответ и ограничивает время ожидания. `login()` получает токен, `channels()` получает список каналов, а `history()` загружает до 20 сообщений. `send()` отправляет текст и передаёт токен в заголовке `X-Auth-Token`. `image()` строит адрес маленькой или полной картинки.
3. **`lib/chat_screen.dart`**. При открытии `initState()` запускает загрузку сообщений и черновика. Метод `_load()` хранит сообщения в `Map` по ID. Для старой страницы он передаёт самый маленький ID в `lastKnownId`. Метод `_saveDraft()` сохраняет ввод. После успешной отправки `_send()` очищает поле и черновик и обновляет историю. Метод `_showImage()` открывает полную картинку. Её можно увеличить.
4. **`lib/chat_storage.dart`**. Метод `_open()` открывает SQLite и при первом запуске создаёт таблицу `drafts`. Ключ черновика состоит из имени пользователя и канала. `draft()` читает черновик. `saveDraft()` сохраняет текст или удаляет пустой черновик. Токен хранится в защищённом хранилище Android. История приходит с сервера и остаётся в памяти открытого чата.

## Что показать преподавателю

1. Войти и открыть канал.
2. Нажать «Загрузить старые сообщения». Открыть картинку и увеличить её.
3. Ввести текст, вернуться к каналам и снова открыть тот же чат. Показать, что текст сохранился. Чтобы проверить перезапуск, закройте приложение без кнопки «Выйти».
4. Отправить текст в канале, где можно делать тесты. Если отправка не подтверждена, сначала обновить чат и проверить историю.
5. Повернуть эмулятор и проверить открытый экран. В конце можно показать выход из аккаунта.

## Короткий рассказ для защиты

> Это чат на Flutter для Android. Пользователь вводит имя и пароль. Сервер даёт токен. После входа можно открыть канал, читать историю и отправлять текст. Приложение загружает до двадцати сообщений за один запрос. Черновики хранятся в SQLite. Токен хранится в защищённом хранилище Android.

## Вопросы и ответы

- **Зачем нужен SQLite?** Чтобы сохранить черновик после закрытия приложения. У каждого пользователя и канала свой черновик.
- **Зачем проверять `mounted` после `await`?** Пользователь мог закрыть экран. Мы проверяем, что экран ещё открыт.
- **Почему сообщения не повторяются?** Ключ в `Map` — ID сообщения. Если ID уже есть, запись заменяется.
- **Что такое токен?** Сервер даёт его после входа. Приложение передаёт его, например, при отправке сообщения.
